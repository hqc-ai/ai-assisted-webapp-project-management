# AI Role Matrix

| Activity | Product Owner | ChatGPT | Kiro | Codex |
|---|---|---|---|---|
| Business objectives | Approves | Structures | Supports baseline | No |
| Product roadmap | Approves | Drafts and reviews | Supports architecture | Implements approved scope |
| Requirements | Approves | Drafts and reviews | Creates initial baseline | Implements |
| Sitemap and routes | Approves | Reviews | Drafts | Implements |
| Data model | Approves | Reviews | Drafts | Implements |
| UI direction | Approves | Creates UI specs | Documents | Implements |
| Content strategy | Approves | Drafts and audits | Structures | Integrates |
| Source code | Reviews result | Reviews reports | Limited | Implements |
| Debugging | Accepts fix | Analyses problem | Limited | Executes fix |
| Git and deployment | Approves | Defines controls | No | Executes |
| CMS and workflow | Approves | Designs process | Supports requirements | Implements |
| CRM and analytics | Approves | Defines use cases | Supports architecture | Integrates |
| AI capabilities | Approves | Designs use cases and governance | Supports architecture | Implements |
| Final acceptance | Responsible | Supports review | No | Provides evidence |

## Governance rule

AI tools may recommend, draft, analyse, and implement.

The Product Owner remains accountable for:

- Scope
- Accuracy
- Business decisions
- Risk acceptance
- Production approval
