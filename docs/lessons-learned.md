# Lessons Learned

1. A complete-looking homepage is not a complete product.
2. UI, content, data, routes, SEO, and deployment must be managed separately.
3. AI tools need clear roles.
4. Historical specifications should not silently override current decisions.
5. Structured content is the foundation for future CMS and AI.
6. Route and ID design must support scale.
7. Local validation should precede cloud deployment.
8. A private source repository and public portfolio repository should be separated.
9. Phase 2 automation should follow stable Phase 1 data.
10. Phase 3 AI should follow approved knowledge and governance.
11. AI features need business value, not only visual appeal.
12. Human approval remains necessary for accuracy, legal claims, and production release.
