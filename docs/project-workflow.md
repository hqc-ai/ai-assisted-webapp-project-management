# Project Workflow

## 1. Business objective

The Product Owner defines business goals, users, services, locations, content priorities, and conversion outcomes.

## 2. Product roadmap

The project is managed in three phases:

1. Structured web platform
2. Operational content and lead platform
3. AI-enabled service and knowledge platform

## 3. Requirement analysis

Requirements are separated into:

- Business
- Content
- UI
- Data
- Route
- SEO/AEO/GEO
- Integration
- Deployment
- AI governance
- Acceptance criteria

## 4. Baseline and architecture

Historical baseline documents are kept for traceability, while current decisions are maintained separately.

## 5. UI and content implementation

The project uses reusable UI templates and structured content collections.

## 6. Validation

Validation includes type checking, build, route inventory, links, canonical, sitemap, mobile, console, and structured data.

## 7. GitHub and deployment

```text
Local development
→ GitHub private repository
→ Cloudflare preview
→ Validation
→ Production release
```

## 8. Phase 2 expansion

After production stability:

- CMS
- Workflow
- CRM
- Analytics
- Automation

## 9. Phase 3 expansion

After sufficient structured data and operational maturity:

- AI service finder
- Knowledge assistant
- Semantic search
- Sales support
- AI governance
