# Security and Disclosure Policy

This public repository excludes:

- Private source code
- Credentials
- Environment variables
- API keys
- Customer data
- Internal pricing
- Confidential business records
- Private project logs
- Local machine paths
- Unapproved screenshots
- Internal Kiro specifications
- Private Codex outputs

The repository presents methods, architecture direction, governance, and lessons learned.

All implementation details that could expose the private 5SOffice project remain in the private repository.
