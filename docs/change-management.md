# Change Management Model

## Change classification

### Minor

- Copy
- Spacing
- Colour
- Small UI correction

### Major

- Route structure
- Schema
- Data model
- Service naming
- SEO rules
- Integration
- Deployment architecture
- AI features

## Traceability

Each significant request receives an ID.

Example:

```text
5S-CX-UI-003
```

The ID may be referenced in:

- Task status
- Change log
- Decision log
- Commit message
- Validation report

## Phase control

Changes are also classified by roadmap phase:

- Phase 1: web foundation
- Phase 2: operational integration
- Phase 3: AI-enabled capability

A Phase 3 feature should not be introduced before the required Phase 1 and Phase 2 foundations are stable.
