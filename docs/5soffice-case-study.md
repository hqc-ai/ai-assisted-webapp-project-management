# 5SOffice Webapp Case Study

## Context

5SOffice provides office-related services across multiple cities and buildings in Vietnam.

The project requires more than a brochure website because content must be organised by:

- Service
- City
- Building
- District
- Administrative area
- News
- Legal knowledge

## Phase 1 achievements

The project has developed:

- Homepage UI
- Structured content collections
- Dynamic service and location routes
- News collection
- Listing and detail-page architecture
- Metadata and canonical handling
- Article and breadcrumb structured data
- Sitemap
- Internal-link validation
- Local build and responsive validation

At one validation milestone:

- 139 content entries were inventoried
- 60 published news entries were loaded
- No duplicate IDs were reported
- No duplicate canonical URLs were reported
- No orphan content was reported
- The local build completed successfully

These figures describe a project checkpoint, not a permanent production metric.

## Phase 2 direction

The next maturity step is to connect the web platform with:

- Content publishing workflow
- CMS
- Lead capture
- CRM
- Analytics
- Conversion tracking
- Automated reports
- Data governance

## Phase 3 direction

The long-term platform can support:

- Natural-language service discovery
- AI service recommendations
- AI knowledge retrieval
- Customer enquiry qualification
- Sales support
- Content consistency monitoring
- Human-controlled AI publishing assistance

## Key management lesson

The project demonstrates that effective AI-assisted development requires coordination across:

```text
Business
+ Product
+ Content
+ UX
+ Data
+ Code
+ Deployment
+ Governance
```

A strong outcome does not come from one AI tool working alone. It comes from defined roles, traceable decisions, structured review, and human accountability.
