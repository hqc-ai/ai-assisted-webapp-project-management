# Architecture Evolution

## Phase 1 architecture

```text
Structured Markdown content
→ Astro Content Collections
→ Reusable components
→ Static routes
→ GitHub
→ Cloudflare Pages
```

Characteristics:

- Low operating cost
- Fast delivery
- Strong crawlability
- Good content control
- Limited operational workflow

## Phase 2 architecture

```text
CMS / editorial workflow
→ Structured content
→ Web application
→ Forms and lead routing
→ CRM
→ Analytics dashboard
→ Automation
```

Characteristics:

- Controlled publishing
- Lead traceability
- Operational reporting
- Role-based workflow

## Phase 3 architecture

```text
Approved knowledge sources
→ Search and retrieval layer
→ AI service and knowledge functions
→ CRM and analytics context
→ Human review and escalation
```

Characteristics:

- Natural-language interaction
- Recommendations
- Knowledge reuse
- AI-assisted operations
- Governance and traceability

## Design principle

Each phase extends the previous one.

The project should avoid replacing a stable foundation with unnecessary complexity.
